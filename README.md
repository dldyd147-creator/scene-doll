# 씬 돌 (Scene Doll)

웹툰 콘티 단계에서 3D 돌로 컷을 짜고, 배치한 돌의 구도와 앵글을 AI가 이해할 수 있는 결과물(이미지 + 텍스트)로 뽑는 브라우저 단독 프로그램입니다. 설치·서버 없이 주소로 열고, 데이터는 사용자가 지정한 작업 폴더에 JSON·PNG로 직접 저장합니다.

기획서: [scene-doll-spec.md](scene-doll-spec.md)

## 실행

- 배포 페이지: https://dldyd147-creator.github.io/scene-doll/
- 로컬 개발: `npm install` 후 `npm run dev` → http://localhost:5173
- 빌드: `npm run build` → `dist/` (정적 파일, 어디에 올려도 동작)
- 배포: `npm run deploy` (빌드 후 `gh-pages` 브랜치에 올림, 1~2분 뒤 반영)
- 테스트: `npm test`, 타입 검사: `npm run typecheck`

푸시할 때마다 자동 배포하려면 `deploy/github-pages.yml`을 `.github/workflows/deploy.yml`로 옮기면 된다. gh CLI 토큰에 `workflow` 권한이 필요하므로 먼저 `gh auth refresh -h github.com -s workflow`를 한 번 실행한다.

대상 환경은 윈도우 데스크탑의 크롬·엣지입니다. 작업 폴더 저장은 폴더 접근 기능(File System Access API)이 있는 브라우저에서만 되고, 그 밖에서는 브라우저 내부 저장(IndexedDB)으로 동작합니다.

## 화면

왼쪽부터 컷 목록 · 원고뷰(+카메라 패널) · 조작뷰 · 에셋 패널. 모든 편집은 조작뷰에서 하고, 원고뷰는 보기·카메라 조작·컷 확정만 합니다.

## 작업 흐름

0. **작품 관리**(시작 화면): 작품을 만들고(코드 3자 + 이름) 회차를 열면 편집 화면으로 간다. 캐릭터 관리에서 작품의 캐릭터를 등록한다: 이름·고정색·성별(돌)·키·나이·역할·한 줄 설명·설명·외형 태그, 레퍼런스 기본 8장(얼굴 정면·측면·반측면·반측면 2·후면, 전신 전면·측면·후면) + 추가 자료(복장·무기 등 이름 붙여 최대 10장), 대표 1장. 편집 화면 상단의 [작품 관리]로 돌아온다.
1. 에셋 패널 **캐릭터** 탭에서 + 를 눌러 그 캐릭터의 돌(성별 돌·키·고정색)을 꺼내고 조작뷰에서 자세를 잡는다. 작품과 무관한 돌은 **돌** 탭에서 필터를 '기본 돌'로 바꿔 꺼낸다(임시 캐릭터가 된다). 씬의 돌 카드에서 캐릭터를 바꿔 지정하거나 임시로 되돌린다.
2. 원고뷰에서 카메라를 잡는다: 드래그로 궤도 회전, Shift+드래그로 팬, 휠로 거리, Ctrl+휠로 화각. 카메라 패널에서 화면비·화각·위치(cm)·각도를 숫자로 끌어 조절한다. [시점] 줄의 아이레벨은 선택한 캐릭터의 눈높이에 수평으로, POV는 그 캐릭터의 눈에서 머리 방향으로 카메라를 놓는다. 조작뷰의 카메라 아이콘을 끌거나 G/R, W/E 기즈모로 옮길 수도 있다.
2-1. **씬 라이브러리·씬 검색기**: 잘 짠 씬은 원고뷰 아래 책갈피 버튼(씬 저장)으로 `공용/씬/`에 넣는다. 인원(화면 안 돌)·샷·앵글·화면비·배치는 프로그램이 자동 태그로 붙이고, 상황 태그(대화·독백·대치·전투·이동·리액션·일상·로맨스·군중·설정샷, 설정에서 편집)만 버튼으로 찍는다. 캐릭터 지정은 저장하지 않고 돌 슬롯(돌 ID·키·위치·회전·관절)·소품·카메라·화면비만 남겨 다른 작품에서도 쓴다. `` ` ``(백틱) 또는 돋보기 버튼으로 **씬 검색기**를 열면 썸네일 격자 위에 태그 버튼 줄(샷·앵글·인원·상황)과 이름 검색이 있다. 버튼을 누르면 걸러지고 다시 누르면 풀린다(같은 묶음은 '또는', 묶음끼리는 '그리고', 상황 태그는 누른 것을 모두 가진 씬만). 썸네일을 고르면 미리보기가 커지고 슬롯마다 이 작품의 캐릭터를 지정한다(비우면 임시 캐릭터). [교체]는 현재 컷의 씬 전체(카메라·화면비 포함)를 바꾸고, [추가]는 돌만 더한다. 어느 쪽이든 지정한 캐릭터의 돌(성별 돌·키·고정색)로 들어온다. 에셋 패널 씬 탭에 최근 저장 씬이 보인다.
2-2. **포즈 라이브러리**(에셋 패널 포즈 탭): 선택한 돌의 관절 회전값을 이름·분류·태그와 함께 `공용/포즈/`에 저장하고, 카드를 누르면 선택한 돌에 적용한다(돌 공간 회전이라 체형과 무관). 분류 칩으로 거르고 카드의 ×로 지운다.
3. **컷 확정**(Ctrl+Enter): 설명 텍스트가 자동 생성되고 썸네일이 컷 목록에 들어가며 다음 컷으로 넘어간다. 다음 컷이 없으면 방금 확정한 씬을 복사해 만든다. PageUp/PageDown으로 위아래 컷 이동, 컷 목록 아래 버튼으로 삽입·삭제·순서 변경.
4. **출력**: 컷 목록의 출력 버튼으로 확정 컷 전체를 `출력/{작품코드}/{회차}/`에 PNG(가로 1024px, 설정 가능) + 컷별 JSON + 회차 설명 `.md`로 내보낸다.
5. **AI 전달 패키지**: 출력 때 '함께 추출'(기본)이면 `패키지/{작품코드}/{회차}/`에 컷 폴더(`{컷}/` PNG + `{코드}_{회차}_{컷}.json` + `prompt.md`), 캐릭터 시트(`캐릭터/{이름}/{이름}.md` + 레퍼런스 복사), `회차.json`, 회차 설명 `.md`가 생긴다. 컷 JSON과 prompt.md에는 화면 안 캐릭터(돌 색 → 이름, 등록 여부, 설명, 외형 태그, 위치·향함·자세, 레퍼런스 경로)와 장면(자동 설명·메모·대사·지문·카메라)이 들어 있어 이미지 API에 그대로 붙인다. 등록되지 않은 돌은 "임의의 남성/여성"으로 그리라고 적힌다.

설명 텍스트는 고정 어휘로 쓴다: 샷 4종(클로즈업·바스트·웨이스트·풀샷), 앵글 3종(하이·아이레벨·로우), 위치 9칸(왼쪽·중앙·오른쪽 × 앞·중간·뒤), 향함 8방위, 자세 문구(관절 각도 규칙). 사람이 고칠 것은 메모 줄뿐이다.

## 조작 (디자인돌 방식)

| 조작 | 동작 |
| --- | --- |
| 몸 부위 드래그 | 그 관절이 바로 회전 |
| 관절점(작은 원) 드래그 | 그 관절이 커서를 따라가도록 위 뼈를 돌림 |
| Alt + 부위 드래그 | 뼈 축 비틀기 |
| 손·발 핸들(큰 원) 드래그 | IK로 팔·다리 전체가 따라옴(어깨 연동 선택). 바닥 아래로는 안 내려감 |
| G (또는 M) | 선택한 돌·카메라 이동(블렌더식): 마우스를 따라오고 클릭·Enter 확정, Esc·우클릭 취소. X/Y/Z 축 고정(블렌더식 표기: Z 위아래, Y 앞뒤, X 좌우) |
| R | 선택한 돌·카메라 회전(수직축). 돌 전체 회전은 R 또는 회전 기즈모로만 한다. X/Y/Z 축 고정 |
| 골반(엉덩이) 드래그 | 발을 바닥에 둔 채 몸을 내리고 올린다(앉히기·일어서기). 다리가 더 못 접히면 거기서 멈추고, 위로 끌면 돌이 들린다. 회전하지 않는다 |
| Q / W / E | 직접 드래그 / 이동 기즈모 / 회전 링 기즈모 |
| 휠 드래그 / Shift+휠 드래그 / 휠 | 시점 회전 / 팬 / 줌 (스케치업) — 설정에서 디자인돌식(우클릭 회전)으로 변경 가능 |
| Shift+Z / F / Tab | 전체 보기 / 선택 돌로 / 조작뷰 ↔ 원고 카메라 시점 |
| 원고→조작뷰 / 조작뷰→원고 | 카메라 패널 맨 아래 왼쪽·오른쪽 끝의 큰 버튼. 원고 카메라 시점을 조작뷰로 가져옴 / 조작뷰 시점을 원고 카메라로 복사 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시하기 |
| Ctrl+C / Ctrl+V / Delete | 돌 복사 / 같은 자리에 붙여넣기 / 삭제 |
| Ctrl+Enter | 컷 확정 → 다음 컷 |
| `` ` `` (백틱) | 씬 검색기 열기/닫기 (Esc로도 닫힘) |
| PageUp / PageDown | 위 컷 / 아래 컷(없으면 복사해 생성) |
| Ctrl+S | 저장 (컷 확정마다, 그리고 1분마다 자동 저장) |

표시 토글: 명암(2단 셀), 십자선(얼굴 중심선·눈높이선·몸통 정중선을 표면에 칠함), 외곽선(실루엣), 격자, 화각선. 포징 보조: 관절 한계(사람 관절이 안 가는 각도로 꺾이지 않게 자동 교정, 끌 수 있음), 어깨 연동, 발 고정(돌을 옮길 때 발이 제자리. 골반 드래그는 항상 발을 고정하고 발바닥을 바닥에 붙여 둔다), 손발 방향 고정. 관절 한계가 켜져 있으면 무릎·팔꿈치 IK는 경첩 축 둘레 굽힘만으로 정확히 풀어(src/engine/ik.ts `solveHingeChain`) 발이 미끄러지지 않는다. 돌에 `…Twist` 뼈가 있으면 팔다리 비틀림을 어깨·고관절 쪽 −50%, 손목·발목 쪽 +50%로 자동 분배한다.

UI는 밝은 테마가 기본이고 설정에서 어둡게 바꿀 수 있다. 상단 오른쪽의 ? 가 도움말, 그림 아이콘이 출력물 보기(브라우저는 탐색기를 직접 열 수 없어 앱 안에서 본다)다.

## 코드 구조

```
src/
  model/      데이터 구조(작품·회차·컷·캐릭터·돌·포즈·씬·소품)와 기본값, 씬·포즈 라이브러리 순수 로직(library: 컷→씬, 필터, 슬롯→돌)
  engine/     three.js 엔진: 뼈대·마네킹/GLB 돌·IK·상호작용·원고 카메라·십자선·외곽선·오프스크린 렌더
  describe/   설명 텍스트: 컷 분석(화면 안 판정·샷·앵글·배치·향함·자세)과 .md 형식
  state/      zustand 스토어(문서·컷 목록·선택·되돌리기·설정)
  storage/    저장소 모듈(작업 폴더 / 브라우저 내부), 폴더 구조, 작품·회차·캐릭터·레퍼런스·썸네일·출력·패키지·공용 씬/포즈 쓰기
  ui/         React 화면: 시작 화면(StartScreen), 캐릭터 관리(CharacterManager), 편집 화면, 씬 저장·검색기(SceneSaveDialog·SceneBrowser), 포즈·씬 탭(PoseTab·SceneTab), 컷 확정·일괄 출력(exporter)·AI 전달 패키지(packager)
```

저장·불러오기는 `storage/` 모듈만 거칩니다. 공유가 필요해지면 이 모듈의 백엔드만 서버리스 저장소로 바꿉니다.

## 돌과 포즈 데이터

- 뼈 이름은 Mixamo 표준(접두어 없음), 휴식 자세는 T포즈.
- 관절 회전값은 **돌 공간에서 휴식 자세 대비 회전 쿼터니언**으로 저장합니다. 뼈의 로컬 축 규약에 의존하지 않아, 같은 이름·T포즈 뼈대를 가진 어떤 돌(코드 마네킹, MakeHuman, 실제 GLB)에도 같은 포즈를 적용할 수 있습니다.
- 기본 돌은 MakeHuman(CC0) 2세대 남·여로, 팔다리에 트위스트 뼈 8개가 있어 비틀림이 어깨·손목에 걸쳐 풀립니다. 캡슐 마네킹은 테스트용입니다. 점검 보고는 [docs/doll-report.md](docs/doll-report.md), 생성 스크립트는 `doll-src/makehuman/`.
