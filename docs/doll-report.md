# 돌 점검 보고 (1단계 하위 1단계)

기획서의 "돌 GLB 내장·점검 보고" 항목에 해당한다. 실제 돌 파일 대신 **코드 마네킹**으로 시작하기로 했으므로(2026-10-24 결정), 코드 마네킹을 같은 항목으로 점검했다. MakeHuman(CC0) 돌은 별도 생성 중이며 결과는 `doll-src/makehuman/report.md`에 둔다.

## 코드 마네킹 (mannequin_m / mannequin_f)

| 항목 | 결과 |
| --- | --- |
| 뼈대 | Mixamo 이름 25개(접두어 없음). 목·어깨(쇄골)·팔꿈치·손목·허리(Spine·Spine1·Spine2)·고관절·무릎·발목 모두 있음 |
| 손가락 뼈 | 없음. 4단계(손가락 쥐기 프리셋)에서 실제 돌 GLB의 손가락 뼈를 쓰거나 마네킹에 추가 |
| 비율 | 7.5등신 기준. 남 175cm·여 162cm 기준 키, 키 입력 시 전체 스케일 |

│                   ├ LeftShoulder ─ LeftArm ─ LeftForeArm ─ LeftHand
│                   └ RightShoulder ─ RightArm ─ RightForeArm ─ RightHand

└ RightUpLeg ─ RightLeg ─ RightFoot ─ RightToeBase ─ RightToe_End

### 외형

- 뼈마다 캡슐·타원체·상자를 붙인 강체 마네킹(스키닝 없음). 관절에서 캡슐의 둥근 끝이 겹쳐 이음새가 보이지 않는다.
- 고정색 단색 + 2단 셀 명암(그늘 0.55). 외곽선·십자선은 하위 4단계에서 붙인다.
- 얼굴 방향 표시(십자선)가 붙기 전까지는 발끝 방향으로 정면을 판단한다.

### 포즈 데이터 호환

관절 회전은 돌 공간·휴식 자세 대비 쿼터니언이라, 뼈 이름이 같고 T포즈인 돌이라면 로컬 축 규약이 달라도 같은 포즈가 적용된다. 실제 돌 GLB를 내장할 때는 (1) 뼈 이름 매핑, (2) T포즈 휴식 자세, (3) 발바닥 y=0·정면 +Z 세 가지만 맞추면 된다.

## MakeHuman 돌 (mh_m / mh_f)

MakeHuman 커뮤니티의 Blender 애드온 MPFB2(v2.0.18, Blender 4.3)로 생성했다. 생성 스크립트·검증 로그·미리보기는 `doll-src/makehuman/`, 상세 보고는 `doll-src/makehuman/report.md`. 라이선스: MakeHuman 출력물은 CC0(저작자 표시 불필요), MPFB2 코드는 GPL이지만 결과물에는 적용되지 않는다.

| 항목 | 결과 |
| --- | --- |
| 파일 | `public/dolls/mh_male.glb` 938KB · `public/dolls/mh_female.glb` 938KB |
| 키 | 남 1.7497m · 여 1.6202m (발바닥 y=0, 정면 +Z) |
| 뼈대 | Mixamo 이름 65개(접두어 없음). 기본 25개 + 손가락 40개. 계층은 코드 마네킹과 동일 |
| 손가락 뼈 | 있음(엄지·검지·중지·약지·소지 각 4마디) → 4단계 손가락 프리셋에 바로 쓸 수 있음 |
| 폴리곤 | 26,756 삼각형(권장 5만 이하), 정점 14,517 |
| 휴식 자세 | T포즈(위팔·아래팔 ±X 정확히 수평, 손바닥 아래) |
| 스킨 | 정점당 최대 4개 뼈, 가중치 정규화, 헬퍼 지오메트리 제거 확인 |
| 남·여 뼈대 구조 | 동일(같은 토폴로지·같은 뼈) |
| 재질 | 단일 재질, 텍스처 없음 → 프로그램이 고정색 셀 재질로 교체 |

### 주의

- 실제 인체 메시라 옷을 입지 않은 형태다. 5단계 이미지 API에 레퍼런스로 넣을 때 생성 거부를 부를 수 있으므로, 필요하면 가슴·골반 형태를 완화한 변형(MakeHuman 매크로 조정) 돌을 추가로 뽑는다. 생성 스크립트에 매개변수가 있어 코드 작업으로 가능하다.
- 부위 클릭 판정은 맞은 삼각형의 스킨 가중치가 가장 큰 뼈로 한다. 부위별 색 강조는 없고 선택 관절 표시(흰 점)로 대신한다.
- 아이·노인·근육·비만 체형은 같은 스크립트의 매크로(age·muscle·weight)만 바꿔 생성하면 된다. 뼈 이름이 같으므로 포즈는 모두 공유된다.

## 2세대 MakeHuman 돌 (mh2_m / mh2_f) — 2026-10-25

실작업 피드백("마네킹은 쓸 수 없다, MakeHuman도 관절 움직임이 자연스럽지 않다")을 받아 다시 생성했다. 메시·키·뼈 이름은 1세대와 같고 다음이 달라졌다. 생성 스크립트는 `doll-src/makehuman/scripts/build_doll_v2.py`, 상세는 `doll-src/makehuman/report_v2.md`, 변형 테스트 렌더는 `doll-src/makehuman/preview_v2/`.

| 항목 | 결과 |
| --- | --- |
| 파일 | `public/dolls/mh2_male.glb` 940KB · `public/dolls/mh2_female.glb` 940KB (삼각형 26,756 동일) |
| 트위스트 뼈 | 8개 추가(LeftArmTwist·LeftForeArmTwist·LeftUpLegTwist·LeftLegTwist와 Right*). 팔다리 뼈 축 위 35%(어깨·고관절 쪽)와 65%(손목·발목 쪽) 지점, 회전 없음. 총 73개 뼈 |
| 트위스트 가중치 | MPFB에는 트위스트 가중치가 없어 팔다리 가중치를 축 방향 램프로 나눠 만들었다(정점별 합 불변). 앱이 어깨·고관절 쪽은 팔다리 비틀림의 −50%, 손목·발목 쪽은 손·발 비틀림의 +80%로 구동한다 |

| 법선 | 전부 부드럽게, UV 이음새에서 법선 불연속 없음 |

### 앱 쪽 보조

돌 품질과 별개로 관절 움직임이 어색해 보이는 원인은 조작 쪽에도 있었다. 다음을 함께 넣었다.

- 관절 한계(스윙 원뿔·비틀림·경첩)와 자동 교정. 팔꿈치·무릎은 한 방향으로만 굽는다.
- 경첩 아래 뼈(아래팔·정강이)를 끌면 위팔·허벅지가 제 축으로 비틀려 경첩 평면이 목표를 품은 뒤 굽는다. IK 뒤에도 같은 처리를 한다.
- 관절점·IK 핸들·골반 핸들을 화면 고정 크기로 그려 관절 위치가 보인다.

## 판정

- 기본 돌은 2세대 MakeHuman(목록의 '남'·'여'). 1세대는 옛 데이터 호환용으로 숨겼고, 캡슐 마네킹은 테스트용으로만 남겼다.
- 남은 한계: 선형 블렌드 스키닝 특성상 팔을 내릴 때 어깨·겨드랑이 주름, 앉을 때 무릎 뒤 주름이 남는다. 더 줄이려면 교정 블렌드셰이프(4단계 이후)나 듀얼 쿼터니언 스키닝이 필요하다.
